The GIF and MP4 show the committed cyan line-art edition, rendered from its actual
HLSL and atlas on Windows Direct3D WARP. This is an offscreen production-shader
capture with simulated anonymous activity, not a recording of Windows Terminal,
user commands or typing latency.

- Source validation: Windows workflow `37481325434` in the private development repository (2026-10-06).
- Public validation: [Windows checks passed](https://github.com/lucatirel/DracoShell/actions/runs/37489460291) for `05f67e176e5e929a09325d1b6e2bf5a2a40c2021`. This repository runs the same checks on every push to `main`.
- Capture artifact: `draco-shader-demo`, ID `11421965211`.
- Capture: 800 x 450 RGBA, 120 frames at 20 fps.
- MP4: full-resolution H.264. GIF: 640 pixels wide, 12 fps, 64-color palette.

The capture shows gentle body motion, ambient storms, simulated green typing
lightning with narrow cores, front/rear occlusion, and red-orange Enter fire. It replaces the prior Mesa/GLSL local review.

The Windows workflow passed parsing, JSON/asset integrity, Direct3D ps_4_0 shader
compilation, setup and reset, quiet startup, anonymous input and transport,
security architecture checks, real Oh My Posh prompt checks, and pixel regression
checks at 640 x 360, 400 x 600 and 400 x 300 panes. Moving and fixed-body modes,
foreground text preservation, fire propagation/shutdown and simultaneous green
lightning were checked with positive and negative shader clocks.

Reproduce by letting the Windows workflow capture this branch, downloading its
`draco-shader-demo` artifact and running:

```powershell
python scripts/encode-demo.py path/to/draco-demo-800x450-20fps.rgba
```

Python/Pillow and ffmpeg are developer tools only. The installed theme does not
require them. The capture is not a benchmark of interactive GPU usage or power.


## All-preset terminal gallery

The README terminal previews include all seven public presets. Each image uses
its committed production HLSL and matching texture rendered through Windows
Direct3D WARP at 1280 × 720. The foreground is the actual ANSI output from Oh My
Posh 31.4.1 using `config/draco.omp.json`, drawn with MesloLGM Nerd Font from
Nerd Fonts v3.4.0. The renderer feeds this text through the shader, so it also
shows how foreground text and graphics interact.

These are reproducible offscreen terminal previews, not photographs or Windows
Terminal recordings. The session uses a disposable Git repository on `main`,
an example Python venv, a directory listing and Git status. No user command
history or personal Terminal settings are captured. Modern packs simulate a
single typing/fire state; legacy packs remain ambient-only. The same frozen
frame cannot demonstrate armored flight or body movement.

Gallery PNGs live under `docs/media/presets/`. `gallery-provenance.json` records
source revision, image/shader hashes, renderer, prompt, font and dimensions.
The original GIF/MP4 remain available for an animated view of the default.

The seven captures were generated by the [successful Windows gallery workflow](https://github.com/lucatirel/DracoShell/actions/runs/38049380616)
at revision `fdcf95950e4399bb1a93c922437cc3b5a1abebf0`.

Reproduce on Windows with the pinned prompt executable and font used in
`.github/workflows/gallery.yml`:

```powershell
# Compile scripts/render-gallery.cpp with Visual Studio's x64 developer tools:
cl /nologo /EHsc /std:c++17 scripts\render-gallery.cpp /Fe:draco-gallery.exe /link d3d11.lib d3dcompiler.lib windowscodecs.lib ole32.lib

# Run with an existing Oh My Posh executable and Meslo Nerd Font file:
$env:RUNNER_TEMP = Join-Path $env:TEMP ("draco-gallery-" + [guid]::NewGuid())
New-Item $env:RUNNER_TEMP -ItemType Directory | Out-Null
$env:GITHUB_SHA = git rev-parse HEAD
.\scripts\capture-gallery.ps1 -Executable path\to\oh-my-posh.exe -Renderer .\draco-gallery.exe -Font path\to\MesloLGMNerdFont-Regular.ttf -Output path\to\gallery
```

The read-only gallery workflow can also be run manually. These capture tools and
font downloads are development-only; installing DracoShell does not require them.
